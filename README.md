# DSB Labs

Offer site for DSB Labs motion flyers, murals and brand kits. Served with GitHub Pages from `main` (root).

- `index.html` is the whole page (HTML, CSS and a little JS in one file).
- `media/` holds the sample videos (720p web versions) and their poster frames.

To change a price or the booking email, edit `index.html` and push.
